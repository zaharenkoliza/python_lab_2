## 1. Постановка

Требовалось развернуть автономного агента на собственном сервере, подключить его к мессенджеру, ограничить доступ, настроить память, инструменты и навык, поставить задачу по расписанию и подтвердить, что агент работает без участия пользователя. ## 2. Среда и требования безопасности (шаги 1–2)

Вместо аренды VPS была создана локальная виртуальная машина, что допускается заданием.

| Параметр | Значение |
|---|---|
| Гипервизор | Lima 2.2.1, тип `vz` (Apple Virtualization.framework), хост — Mac на Apple Silicon |
| Гостевая ОС | Ubuntu 24.04.5 LTS, архитектура aarch64 |
| Ресурсы | 2 vCPU, 2 ГиБ RAM, диск 20 ГиБ |
| Стоимость | 0 ₽ (локальный запуск) |
| Команда создания | `limactl start --name=hermes --cpus=2 --memory=2 --disk=20 --mount-none template:ubuntu-24.04` |

Выполненная базовая настройка:

1. Обновление пакетов: `apt-get update && apt-get upgrade`.
2. Вход по SSH-ключу, который генерирует Lima. Парольной аутентификации у пользователя нет, SSH-порт виртуальной машины проброшен только на адрес 127.0.0.1 хоста.
3. Пользователь виртуальной машины непривилегированный (uid 501).
4. Межсетевой экран `ufw`: входящий трафик запрещён, исходящий разрешён, открыт только порт 22/tcp. Статус `active`.

Соблюдение обязательных требований безопасности:

| Требование | Как выполнено |
|---|---|
| Отдельная машина без личных данных | Каталоги хоста в гостевую систему не монтировались (параметр `--mount-none`); каталог `/Users` в госте отсутствует |
| Непривилегированный пользователь | Работа ведётся от пользователя с uid 501; внутри контейнера агент работает под пользователем `hermes` (uid 10000) |
| Только свой идентификатор в списке разрешённых | `TELEGRAM_ALLOWED_USERS` содержит один идентификатор, `GATEWAY_ALLOW_ALL_USERS=false` |
| Ключи и токены вне репозитория | Хранятся в `~/.hermes/.env` на виртуальной машине (права 600); перед каждой публикацией репозиторий проверялся поиском по фрагментам ключей |
| Лимит расходов до первого запуска с планировщиком | Лимит ключа задан, см. раздел 4. Примечание: первоначально лимит ключа составлял 100 долларов и был снижен до 1 доллара уже после запуска планировщика; все прогоны выполнялись на бесплатной модели, расход равен нулю |

Ограничение среды: виртуальная машина работает, только пока включён хост.

| 6 | На запрос «дайджест» вместо публикаций arXiv выдан обзор новостных сайтов | Навык без описательного заголовка не выбирается по смыслу запроса | Результат содержал ссылки на новостные сайты, а не на `arxiv.org/abs` | В навык добавлен заголовок с названием и условиями; запрос, где упомянута arXiv, теперь даёт дайджест arXiv. На общее слово «дайджест» навык по-прежнему не срабатывает |

## 16. Вывод

Hermes Agent, развёрнутый в Docker на локальной виртуальной машине и подключённый к Telegram и бесплатной облачной модели, работает автономно. После перезагрузки виртуальной машины контейнер запускается сам. Задача планировщика выполняется без участия пользователя, результат доставляется в мессенджер. Доступ ограничен идентификатором владельца; обращения постороннего аккаунта отклонены и записаны в журнал. Для условий лабораторной работы этого достаточно.

Практика показала следующие ограничения.

1. Бесплатная модель ненадёжна: одна из четырёх попыток запуска завершилась ошибкой 429, в двух ответах встретилось смешение языков. Требуются резервные модели и проверка результатов человеком.
2. Расход токенов нестабилен (122 тыс., 109 тыс., 412 тыс. при одном задании). На платной модели такой разброс стал бы разбросом стоимости.
3. Безопасность определяется конфигурацией: список разрешённых пользователей и отсутствие общих каталогов с хостом. Доступ к боту равнозначен доступу к машине, поэтому ключи нужно отзывать после завершения работы.
4. Срабатывание навыка зависит от формулировки запроса и описания условий; общий запрос без упоминания источника навык не вызвал.
5. Автономность ограничена доступностью хоста: при остановке хоста агент не работает.

Агенту целесообразно поручать рутинный сбор и первичную систематизацию источников при обязательном указании ссылок и проверке человеком. Формулировку выводов, интерпретацию результатов и действия с необратимыми последствиями передавать агенту не следует.
