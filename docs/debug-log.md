# Журнал отладки

Все записи относятся к реальным событиям при выполнении работы; та же таблица включена в [отчёт](P1-deployment-report.md), раздел 14.

| № | Текст ошибки | Гипотеза | Проверка | Решение |
|---|---|---|---|---|
| 1 | `[Telegram] Connect attempt 1/8 failed: Timed out`; `gateway.run: ✗ telegram error: telegram connect timed out after 45s` | Telegram недоступен из сети или из контейнера | `curl https://api.telegram.org/` из виртуальной машины и из контейнера вернул код 302 за 0,3 с, имя разрешается в 149.154.166.110: сеть исправна | Вмешательство не потребовалось: шлюз сам переподключился примерно через 30 секунд (`Connected to Telegram (polling mode)`). После первого старта следует подождать около минуты, прежде чем искать неисправность |
| 2 | `API call failed after 3 retries. HTTP 429: Provider returned error`, `provider=openrouter model=google/gemma-4-31b-it:free`; в Telegram: «rate-limited … No backup provider is configured» | Общий пул бесплатных моделей OpenRouter перегружен | Ручной запуск `hermes cron run` дал ту же ошибку (запись `failed`, 11,6 с, токенов нет); сеть и ключ исправны (`/api/v1/models` возвращает 200) | Добавлена цепочка резервных моделей `fallback_providers`, контейнер перезапущен. 08.11.2026 при повторной ошибке 429 шлюз переключился на запасные модели и ответил за 5,0 с (снимок [img/dialog.png](img/dialog.png)). Оговорка: если недоступны все бесплатные модели, ответа не будет |
| 3 | В дайджесте прогона 1 ([logs/cron/run-2026-10-29_14-53-26.md](logs/cron/run-2026-10-29_14-53-26.md), строка 59): «фреймворк自我эволюции» | Слабая бесплатная модель смешивает языки | Поиск иероглифов по трём результатам: одно вхождение в прогоне 1; в прогонах 2 и 3 нет. Позднее, при проверке навыка 08.11.2026, в ответе агента также встретилось японское слово в русском тексте | Исправление в навык не вносилось. Дефект подтверждает необходимость проверки результата человеком |
| 4 | `mkdir: cannot create directory ‘/Users’: Permission denied` при копировании файлов на виртуальную машину | Путь `~` раскрылся командной оболочкой хоста, а не гостя | Вывод ошибки содержит путь хоста `/Users` | Команда выполнена с заключением пути в одинарные кавычки и с абсолютным путём гостя |
| 5 | `grep: /home/…/.hermes/config.yaml: Permission denied` | Файлы конфигурации принадлежат пользователю контейнера (uid 10000), пользователь виртуальной машины прочитать их не может | `ls -ld` показывает владельца 10000 | Чтение выполняется через `sudo`. Это же ограничивает доступ других локальных пользователей к ключам, поэтому права не менялись |
| 6 | На запрос «дайджест» вместо публикаций arXiv выдан обзор новостных сайтов | Навык без описательного заголовка не выбирается по смыслу запроса | Результат содержал ссылки на новостные сайты, а не на `arxiv.org/abs` | В навык добавлен заголовок с названием и условиями; запрос, где упомянута arXiv, теперь даёт дайджест arXiv. На общее слово «дайджест» навык по-прежнему не срабатывает |
