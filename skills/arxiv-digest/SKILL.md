# Навык: дайджест новых публикаций arXiv

## Когда включать
- По расписанию (каждый день в 09:00) или по запросу «дайджест», «что нового в arXiv».

## Что делать
1. Взять темы из MEMORY.md (раздел «Проекты»).
2. Загрузить https://export.arxiv.org/api/query?search_query=<тема>&sortBy=submittedDate&max_results=30 для каждой темы.
3. Отобрать работы по смыслу (не по точному совпадению слов): оставить те, чья аннотация относится к теме; максимум 10.
4. Для каждой: название, авторы, дата, ссылка arxiv.org/abs/..., 1 строка о сути (только из аннотации).
5. Отправить одним сообщением в Telegram.

## Обработка отказов
- Источник недоступен/ошибка HTTP/429: написать «Источник недоступен: <код>», дайджест не формировать, ничего не додумывать.
- Пустой результат: написать «Новых релевантных работ нет».
- Каждая ссылка должна быть взята из ответа API; не создавать ссылки по памяти.

## Формат результата
Нумерованный список; в конце строка «Источник: arXiv API, запрос выполнен <дата-время UTC>».
